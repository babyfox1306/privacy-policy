Learn Before Play / Учись и играй

Privacy Policy · Effective date: 6 September 2026

English

Short version: Learn Before Play works locally on the Android device. The current version has no account, backend, advertising SDK, analytics SDK, cloud sync, or remote API, and it declares no Android INTERNET permission.

Data stored on the device

The app stores only local state required to provide the product:

  • whether the AccessibilityService disclosure was accepted;
  • a salted cryptographic hash of the parent PIN and its random salt;
  • package names of apps selected by the parent for gating;
  • the selected learning rule;
  • temporary unlock-expiry timestamps for gated apps;
  • total completed-challenge count;
  • total earned-minute count.

The parent PIN itself is not stored as plaintext. Android application backup is disabled for the app.

AccessibilityService

Learn Before Play uses Android AccessibilityService for a narrow app-gating function. It observes foreground package events so it can determine whether an app selected by a parent has been opened and whether a local learning gate should be shown.

The service is configured with android:canRetrieveWindowContent="false". The current version does not use AccessibilityService to retrieve screen text, messages, passwords, typed text, or accessibility node content. It does not automate taps or actions inside other apps.

Gating does not start until the in-app Accessibility disclosure has been accepted and parent PIN setup is complete. The service can be disabled at any time in Android Accessibility settings.

Network, advertising, analytics, and accounts

The current version contains no account system, cloud sync, advertising SDK, analytics SDK, remote API, or social/chat system. Because the app has no Android INTERNET permission, the app itself cannot directly transmit its local state over the network.

Children

Learn Before Play is configured by a parent or guardian. A child may interact with the local learning gate. The current version does not create child accounts, collect contact information, run advertising, or transmit behavioral analytics.

Deleting local data

Local app data can be removed by clearing Learn Before Play app data in Android Settings or by uninstalling the app. Inside parent controls, the parent can also revoke current reward windows and reset challenge/minutes activity counters.

Security boundary

Learn Before Play is not device-owner/MDM software. Someone with sufficient device-settings access may disable AccessibilityService, uninstall the app, clear app data, or otherwise bypass the casual parent-control boundary. The app does not claim to be tamper-proof.

Changes

If a future version adds networking, accounts, analytics, advertising, cloud sync, or additional sensitive permissions, this policy will be updated before that version is released.

Русский

Кратко: приложение «Учись и играй» работает локально на Android-устройстве. В текущей версии нет учётных записей, серверной части, рекламных или аналитических SDK, облачной синхронизации и удалённого API. Приложение также не запрашивает Android-разрешение INTERNET.

Данные, хранящиеся на устройстве

Приложение хранит только локальные данные, необходимые для его работы:

  • факт принятия уведомления об использовании AccessibilityService;
  • криптографический хэш родительского PIN-кода с солью и случайную соль;
  • имена пакетов приложений, выбранных родителем для ограничения;
  • выбранное учебное правило;
  • временные метки окончания предоставленного доступа;
  • общее число выполненных заданий;
  • общее количество заработанных минут.

Сам родительский PIN-код не хранится в открытом виде. Резервное копирование данных приложения средствами Android отключено.

AccessibilityService

«Учись и играй» использует Android AccessibilityService только для ограниченной функции контроля запуска выбранных приложений. Сервис отслеживает события активного пакета, чтобы определить, было ли открыто приложение, выбранное родителем, и нужно ли показать локальное учебное задание.

Сервис настроен с параметром android:canRetrieveWindowContent="false". Текущая версия не использует AccessibilityService для чтения текста на экране, сообщений, паролей, вводимого текста или содержимого accessibility-узлов. Приложение не автоматизирует нажатия и действия внутри других приложений.

Ограничение приложений не включается до тех пор, пока пользователь не подтвердит уведомление об AccessibilityService и не настроит родительский PIN-код. Сервис можно отключить в любой момент в настройках специальных возможностей Android.

Сеть, реклама, аналитика и аккаунты

В текущей версии нет системы аккаунтов, облачной синхронизации, рекламных SDK, аналитических SDK, удалённого API или социальной/чат-функции. Поскольку приложение не имеет Android-разрешения INTERNET, оно не может напрямую передавать своё локальное состояние по сети.

Дети

Приложение настраивается родителем или опекуном. Ребёнок может взаимодействовать с локальным учебным экраном. Текущая версия не создаёт детские аккаунты, не собирает контактные данные, не показывает рекламу и не передаёт поведенческую аналитику.

Удаление локальных данных

Локальные данные можно удалить через очистку данных приложения в настройках Android или удалив приложение. В родительских настройках также можно немедленно отменить активные периоды доступа и сбросить счётчики выполненных заданий и заработанных минут.

Граница защиты

«Учись и играй» не является системой Device Owner/MDM. Пользователь с достаточным доступом к настройкам устройства может отключить AccessibilityService, удалить приложение, очистить его данные или иным способом обойти обычное родительское ограничение. Приложение не заявляет о полной защите от обхода.

Изменения политики

Если в будущей версии появятся сетевые функции, аккаунты, аналитика, реклама, облачная синхронизация или дополнительные чувствительные разрешения, эта политика будет обновлена до выпуска такой версии.
